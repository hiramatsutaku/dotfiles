# ドキュメントとコードが食い違うときは既存コードに従わせる

Claude Code / Codex は CLAUDE.md / AGENTS.md と既存コードが食い違うと古い記述に従いがち、という研究（ジョージア工科大など）を
紹介する投稿を受け、そこで推奨されていた英文を原文のまま `claude/rules/doc-code-drift.md` に置いた（論文そのものは未確認）。

`~/.claude` 配下の個人ルールは対象外とした。SHA ピン留めのように、既存コードが守っていなくても意図して強制したいルールがあるため。
Codex 用には、除外対象を `~/.codex/AGENTS.md` 自身に読み替えた同等のルールを git 管理外の `~/.codex/AGENTS.md` に置いている。
