# PR・issue・ブランチは URL で挙げる

4 つのリポジトリにまたがる作業で、マージしてほしい PR を `#123`・`other-repo#45` のように番号だけで並べたら、
「リンクにしてー」と言われた。どのプロジェクトでも同じなので、`claude/rules/github-links.md` に置き、
毎回読み込まれる全体の rules にした。

- 対象は、ユーザーが開いて操作するものの一覧に絞った。文中で同じものを何度も指すたびに URL を書くと、返事が読みにくくなるため
- コミットメッセージ・PR の本文・issue のコメントは対象外にした。GitHub が `#番号` をリンクにするので、URL を書くとかえって長くなる
